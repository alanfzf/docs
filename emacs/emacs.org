** Selection commands
"C-space" start selection
"C-x-space" start rectangle

** Split handling
1. "C-x-0" close split
2. "C-x-2" do a vertical split
3. "C-x-3" do a horizontal split
4. "C-x-o" move between splits

** Miscellaneous
1. "C-g" abort keychord?
2. "M-z-<character>" to delete upto a character
3. "C-s-<character>" go to character incremental search
4. "C-x-C-e" evaluate current line
5. "C-x-b" switch to buffer
6. "C-x-d" open dired
7. "C-M-SPC" select matching parent this means: (,[,{,"
8. "M-^" runs delete-indentation or the equivalent of vim's shift+j

* Emacs cheat sheet (Second try)

** Misc commands
1. Cancel any command actually running on emacs =<C-g>=

** Function movement
1. Select a whole function =<C-M-h>= code block
2. Delete content inside of sexp =<C-M-k>=
3. Move up one level in the sexp =<C-m-u>=

** Rectangle mode
1. To enable rectangle mode you type =<C-x><SPC>=
2. To do operations like appending text you do =<C-x> r t=
3. To uppercase the region you do =<C-x><C-u>=
4. To number the region you do =<C-x> r N=

** Blank space deletion
1. =M-\=  delete horizontal spaces/tabs
2. =C-x C-o=  delete extra blank lines
3. =M-^=  join the current line with the previous line

** Character replacemenet
1. =C-M-%= replace a char
2. =!= to replace all occurences

** Uppercase/Lowercase
1. =<M-c>= capitalize first letter of next word
